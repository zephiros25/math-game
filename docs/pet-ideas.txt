MATH RUN · 100 PET IDEAS WITH CHATGPT PROMPTS
==============================================

How to use:
1. Start a NEW ChatGPT chat for each pet and paste Prompt 1.
2. In the same chat, paste Prompt 2 (eyes closed), then Prompt 3 (mouth open).
3. Copy each picture into the Studio (Pets page): Prompt 1 -> "idle",
   Prompt 2 -> "blink", Prompt 3 -> "talk". The tagline goes in "Tagline".
4. If the pet moves or changes size between pictures, ask again with:
   "keep the exact same pose, size and position as the first image".
