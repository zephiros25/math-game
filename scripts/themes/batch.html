  1. For each card: Copy prompt A into a new ChatGPT chat, and Copy prompt B into another. Start them all; ChatGPT works on them at the same time. The prompts start with the theme name and 1 (background) or 2 (icon + button), so ChatGPT usually names the chats that way.
  2. When a theme’s pictures are ready: click its card (it turns orange), then download both pictures in ChatGPT. The Studio picks them up: tall = background, wide = icon + button.
  3. Ctrl+V pastes into the orange card; you can also drop pictures on any card. A finished card turns grey and the next one becomes orange.
